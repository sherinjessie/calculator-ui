# 🧮 Modern Calculator Web App

A modern, responsive, and interactive calculator built using **HTML**, **CSS**, and **JavaScript**. Designed with a sleek dark-themed user interface, this application performs accurate mathematical calculations while providing a smooth and user-friendly experience across desktop and mobile devices.

---

## ✨ Features

- ➕ Perform basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- 🖥️ Fully responsive design for desktop, tablet, and mobile devices
- 🎨 Elegant dark-themed modern user interface
- ⚡ Fast and accurate real-time calculations
- 🧹 Clear (AC) and Delete (DEL) functionality
- 📱 Clean, intuitive, and user-friendly layout
- 💻 Built entirely with vanilla HTML, CSS, and JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## 🎯 Purpose

This project was developed to strengthen my front-end development skills by building a fully functional calculator using core web technologies without relying on external libraries or frameworks.
